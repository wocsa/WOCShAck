API Reference

The VRC Developer API allows you to manage your CSS projects, listings, and analytics programmatically.

🔗 Interactive API Documentation

Try out API endpoints directly in your browser with our Swagger UI, or download the OpenAPI spec to import into tools like Postman.

Open Swagger UI Download OpenAPI Spec

Authentication

All authenticated API requests require an API key passed in the X-API-Key header:

X-API-Key: vrc_your_api_key_here

You can create and manage API keys from the API Keys page.

Rate Limits

Default rate limits are 60 requests/minute and 5,000 requests/day. These can be configured per API key.

Endpoints

Public (No Auth Required)

GET /api/css/

List all CSS files with pagination, sorting, and filtering

GET /api/css/search/?q=keyword

Search CSS files by name, description, or category

GET /api/categories/

List all available categories

GET /api/css/<uuid>/

Get details of a specific CSS file

Your CSS Projects (Auth Required)

GET /api/css/my/

List all your CSS projects

POST /api/css/create/

Create a new CSS project

POST /api/css/<uuid>/update/

Update an existing CSS project (owner only)

DELETE /api/css/<uuid>/delete/

Delete a CSS project (owner only)

Commerce (Auth Required)

GET /api/css/purchased/

List all your purchased CSS files

POST /api/css/<uuid>/purchase/

Purchase a CSS file

GET /api/css/<uuid>/download/

Download a CSS file you own or purchased

Analytics (Auth Required)

GET /api/analytics/?days=30

Get sales analytics for the specified period

Response Format

{
    "status": "success",
    "data": { ... },
    "meta": {
        "page": 1,
        "total": 25
    }
}

Error Codes

401 — Invalid or missing API key

403 — Insufficient scopes

429 — Rate limit exceeded

500 — Internal server error
