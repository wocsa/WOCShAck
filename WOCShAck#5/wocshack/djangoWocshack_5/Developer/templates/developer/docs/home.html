Getting Started

Welcome to the VRC Developer Portal! This guide will help you get up and running with creating, publishing, and monetizing your CSS creations.

Quick Start

  1. Purchase the Developer Role from the Account Store (99 Neuros)
  2. Set up your Developer Profile with your display name and links
  3. Choose a Subscription Plan that fits your needs
  4. Create your first CSS Project using the built-in editor
  5. Publish your project to the marketplace
  6. Track your Analytics and manage Payouts

Editor

The CSS Editor features a full CodeMirror editor with syntax highlighting, live preview, and built-in tools for minifying, beautifying, validating, and prefixing your CSS.

Save your work with Ctrl+S (or Cmd+S on Mac). Create version snapshots to track changes over time.

Publishing

When your CSS project is ready, publish it as a marketplace listing. You can set pricing tiers, license types, and create promotional codes. Your listing goes through a review process before becoming publicly available.

Monetization

Earn Neuros from sales of your CSS creations. The default commission rate is 70% — you keep 70% of each sale. Set up a payout method to withdraw your earnings.

API Access

Generate API keys to integrate programmatically with the VRC Developer Platform. Set up webhooks to receive real-time notifications about sales, reviews, and other events.
