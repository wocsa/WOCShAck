Webhooks

Webhooks allow you to receive real-time HTTP notifications when events occur on your developer account.

Event Types

  • sale.completed
    Triggered when a customer purchases one of your CSS listings
  • sale.refunded
    Triggered when a sale is refunded
  • listing.published
    Your listing has been approved and published
  • listing.rejected
    Your listing was rejected during review
  • review.created
    A customer left a review on your listing
  • payout.completed
    Your payout has been processed
  • subscription.renewed
    Your developer plan subscription was renewed
  • subscription.cancelled
    Your developer plan subscription was cancelled

Payload Format

{
    "event": "sale.completed",
    "data": {
        "listing_id": "uuid-here",
        "customer": "username",
        "amount": "19.99",
        "currency": "NE"
    },
    "timestamp": "2025-01-15T10:30:00Z",
    "webhook_id": "uuid-here"
}

Signature Verification

Every webhook delivery includes an X-Webhook-Signature header containing an HMAC-SHA256 signature of the payload using your webhook secret.

import hmac
import hashlib

def verify_webhook(secret, payload, signature):
    expected = hmac.new(
        secret.encode('utf-8'),
        payload,
        hashlib.sha256
    ).hexdigest()
    return hmac.compare_digest(expected, signature)

Retry Policy

Failed deliveries are retried up to 3 times. After 10 consecutive failures, the webhook is automatically deactivated. You can re-enable it from the webhook settings.

Headers

Each delivery includes these headers:

Content-Type: application/json
X-Webhook-Signature: hmac-sha256-hex-digest
X-Webhook-Event: sale.completed
User-Agent: VRC-Developer-Webhooks/1.0
